# test-kit — средства тестирования VoidAC

| Файл | Что это |
|---|---|
| `VoidAC-Test-XRay.mcpack` | Ресурс-пак: прозрачный камень. Проверяет anti-esp и Anti-Xray |
| `build_testpack.py` | Сборка пака из исходника (только stdlib, ничего не качает) |
| `КАК-ТЕСТИРОВАТЬ.md` | Почему `.mcpack` не может быть читом + чем тестировать остальное |

## Важно про границы

`.mcpack` — ресурс-пак, а не программа. Он меняет только внешний вид и не
может отправлять пакеты, поэтому боевых читов (KillAura, Fly, Nuker) в этом
формате не существует — не из-за сложности, а из-за отсутствия механизма.

Подробно: `КАК-ТЕСТИРОВАТЬ.md`.
